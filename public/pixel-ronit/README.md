# Pixel Ronit

`poses.png` is the transparent four-pose atlas, generated with the built-in image generation tool from the approved Pixel Ronit concept. The original generated file remains in Codex's generated_images directory. Rendering uses clipped SVG viewports so all appearances share one cached image. No external service is needed at runtime.

Generation prompt:
Create production transparent PNG sprite sheet for the approved Pixel Ronit character in reference image. Preserve his recognizable swept black hair, warm brown skin, smile, navy sweater white collar blue neckline, charcoal trousers and white trainers. Crisp charming pixel art exactly like reference, simplified for 100px web display. Layout: square canvas divided into exactly FOUR EQUAL square quadrants 2 by 2, invisible grid. Each quadrant holds one complete full-body character centered, consistent head size and full body scale, every sprite entirely inside its cell with 12 percent empty padding on all sides. Top left: waving hello standing. Top right: thinking hand on chin standing. Bottom left: seated on small wooden cube using laptop. Bottom right: standing holding phone prototype smiling. GENUINELY TRANSPARENT background and all gutters, no background colors, no shadows, no text, no labels, no decorations, no thought bubbles, no panels. Keep pose silhouettes separated, no elements cross quadrant borders. This is a sprite atlas not a presentation sheet.
